Constraints:

* Each note can have zero or more tags stored as free-text strings.
* Tags should display as small chips next to each note title in the notes list view.
* Add a filter bar at the top with options like "All", "personal", "work", etc.
* Clicking a filter only shows notes containing that tag.
* Do not break existing functionality or tests.
* Prevent duplicate tags on the same note.

Files:

* Update the note model/data structure.
* Update the notes list template/UI.
* Update or add tests for tags and filtering behavior.

Acceptance:

* Existing tests still pass.
* New tests verify that:
  * tags are stored correctly
  * duplicate tags are removed
  * filtering by tag works
  * notes without matching tags are hidden
* Running the app shows visible tag chips and a working filter bar.
