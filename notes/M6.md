# M6 — Other Tools Tour

## Copilot — installed/demo'd
- The VS Code GitHub Copilot demo showed how AI can quickly generate code suggestions and autocomplete functions directly inside the editor, which can speed up development for simple tasks. It was also interesting to see that developers still need to review and test the generated code carefully because the AI can produce bugs or insecure solutions that look correct at first glance.

## Cursor (or Windsurf) — installed/demo'd
- Cursor felt more useful for making quick changes because it could directly edit multiple files in the project while keeping the surrounding codebase the same. Claude seemed better for higher-level reasoning planning larger features where understanding the overall design mattered more.

## Gemini CLI (or Codex CLI) — installed/demo'd
- Gemini CLI felt faster about searching through the codebase, while Claude gave more organized explanations about how the app was structured.

## Chat (Claude.ai or ChatGPT) — used for
- Claude caught that there was quite a bit of dead code that was being unused for this functionality which was a good catch, and I would expect this to be caught by a junior dev.
